# CubeRunner

[![MIT License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Unity 6000.6.4f1](https://img.shields.io/badge/Unity-6000.6.4f1-black?logo=unity)

CubeRunner is a minimalist endless runner built with Unity for Android. Avoid obstacles, survive as long as possible, and beat your high score.

CubeRunner is an independent open-source game in early development. Gameplay has not been implemented yet.

## Features

Planned features:

- Endless runner gameplay with simple cube-based graphics.
- Tap on Android or press Space in the Unity Editor to jump.
- Obstacle avoidance and survival-based scoring.
- Game Over and Restart.
- Offline gameplay.

## Requirements

- Unity Editor 6000.6.4f1 (Unity 6.6).
- Android Build Support for Android builds.

## Getting Started

1. Clone this repository: `git clone https://github.com/alirezasaremi/CubeRunner.git`.
2. In Unity Hub, add the cloned `CubeRunner` folder as a project.
3. Select Unity Editor 6000.6.4f1, then open the project.

## Controls

Planned controls, not yet implemented:

- Android: Tap to jump.
- Unity Editor: Press Space to jump.

## Project Structure

- `Assets/` contains Unity assets and the existing template scene.
- `Packages/` contains package configuration and the dependency lock file.
- `ProjectSettings/` contains Unity project settings.

## Development Status

The project is in early development. The repository foundation is being prepared before gameplay work begins.
